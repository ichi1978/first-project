北陽電機 UST-10 × BrightSign 連携ガイド

LiDAR測域センサ（UST-10LX / UST-10LN）とサイネージプレーヤーBrightSignを組み合わせた、インタラクティブ空間演出・人感トリガーの実装マニュアル

UST-10LX (Ethernet / SCIP) UST-10LN (I/O接点 / Area) BrightSign Series 4 / Series 5

UST-10シリーズの選定と連携方式の違い

「UST-10」には通信仕様が異なる2種類の代表モデルが存在します。どちらの型番を使用するかによって、BrightSignとの接続方式が完全に分かれます。

UST-10LN（エリア検知型）

  • 通信: I/O信号（フォトカプラ出力）
  • 得意なこと: 人が近づいたら検知、通過検知（トリップワイヤ）
  • BrightSign連携: GPIO端子 に直接（リレー経由）接続
  • 特徴: PC不要・設定がシンプル・誤作動が少なく安定

UST-10LX（データ出力型）

  • 通信: Ethernet（SCIPプロトコル TCP/IP）
  • 得意なこと: タッチ位置座標、複数人トラッキング、動的エリア
  • BrightSign連携: UDPネットワーク通信 または 内蔵Node.js
  • 特徴: 高度なインタラクティブ体験が可能

💡 どちらを選ぶべき？

「人が近づいたら動画Aから動画Bに切り替える」だけであれば UST-10LN + GPIO が最も堅牢でトラブルがありません。
「触った壁の位置でエフェクトを出す」「複数ゾーンを細かく制御したい」場合は UST-10LX + UDP/Node.js を選択します。

UST-10LN（I/O型）と BrightSign GPIO の接続

UST-10LN のハードウェア接点出力を、BrightSign の GPIO ポート（DB-15またはフェニックス端子）に入力します。

⚠️ 電気仕様に関する最重要注意事項（破損防止）

BrightSignのGPIO端子は 3.3V プルアップ回路 です。GNDと短絡（無電圧a接点）することで「ボタンが押された」と認識します。
一方、UST-10LNの電源は DC12V または DC24V で駆動し、出力はオープンコレクタです。
絶対にセンサの出力をBrightSignに直接印加しないでください。BrightSignのメインボードが破損します。
必ず リレー（オムロン G2R等） または フォトカプラ絶縁ボード を挟んで無電圧接点（ドライコンタクト）に変換してください。

配線フロー

[UST-10LN] (DC12V/24V) ├─ 電源(+) ─────── DC 12V/24V 電源 (+) ├─ 電源(-) ─────── DC 12V/24V 電源 (-) └─ 出力1(検知) ───┐ │ [メカニカルリレー / フォトカプラ] │ ├─── 接点 COM ─── BrightSign GPIO GND (Pin 11など) └─── 接点 NO ─── BrightSign GPIO Pin 0〜7 (Pin 1〜8)

BrightAuthor:connected の設定手順

1
インタラクティブ プレゼンテーションを作成

ゾーンタイプを「Interactive」にして、待機動画（Loop）と再生動画を配置します。

2
GPIO イベントを追加

待機動画から再生動画へ「GPIO Input」トランジションを引きます。配線したピン番号（例：Button 0）を選択し、「Press」または「Down」を指定します。

3
タイムアウトまたは終了イベント

再生動画の終了時（Media End）または検知が切れた後に待機動画へ戻るトランジションを設定します。

UST-10LX + 中継機（Raspberry Pi / 小型PC）+ UDP連携

展示会や商業施設で最も実績が多く、調整やキャリブレーションが容易な構成です。

[UST-10LX] ──(LAN / TCP 10940)──> [Raspberry Pi / PC] │ │ SCIP解析 & エリア座標判定 │ UDPパケット送信 ("ZONE1_TRIGGER") ▼ [BrightSign] (UDP受信: ポート5000) ▼ [ディスプレイ切替]

中継機用 Python スクリプト（例）

import socket
import time

# 設定
BRIGHTSIGN_IP = "192.168.0.50"
BRIGHTSIGN_PORT = 5000

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

def send_trigger(command_str):
    message = command_str.encode('utf-8')
    sock.sendto(message, (BRIGHTSIGN_IP, BRIGHTSIGN_PORT))
    print(f"Sent UDP to BrightSign: {command_str}")

# エリア内侵入を検知したときの送信例
if __name__ == "__main__":
    # 実際にはUST-10LXのSCIPデータを解析して判定
    send_trigger("ENTER_ZONE_A")

BrightSign側の設定 (BrightAuthor:connected)

  • UDPレシーバー設定: プレゼンテーションプロパティ > 「Interactive」タブ > UDP Receiver Port を 5000 に設定。
  • UDPイベントの設定: 待機状態から再生状態への矢印に「UDP Event」を配置し、受信文字列に ENTER_ZONE_A を指定。

BrightSign単体でUST-10LXを直結制御（Node.js利用）

外部PCを一切使わず、BrightSign Series 4 / 5（HD/XD/XT）のChromium + Node.js機能を使い、センサと直結します。

💡 BrightSignのNode.js環境

BrightSign OS 8.x/9.xでは、HTML5ウィジェット上でNode.jsの標準モジュール（net, dgram等）がネイティブ動作します。外部ライブラリを入れずとも、標準のソケット通信でSCIPプロトコルを制御できます。

実装コード例（HTML5 / JavaScript）

<!DOCTYPE html>
<html>
<body>
  <h1 id="status">LiDAR Standby...</h1>

  <script>
    // Node.jsのnetモジュールを使用
    const net = require('net');
    const dgram = require('dgram');

    const SENSOR_IP = '192.168.0.10';
    const SENSOR_PORT = 10940;

    const client = new net.Socket();

    client.connect(SENSOR_PORT, SENSOR_IP, () => {
      console.log('Connected to UST-10LX');
      document.getElementById('status').innerText = 'LiDAR Connected';
      
      // SCIP 2.0 スキャン開始コマンド (例: MD0000108000001)
      client.write('MD0000108000001\n');
    });

    client.on('data', (data) => {
      const response = data.toString();
      // SCIP 2/3文字エンコードされた距離データをデコードしエリア判定
      // しきい値内の反応があれば、ローカルBrightSignや画面を更新
    });

    client.on('error', (err) => {
      console.error('Socket error:', err);
    });
  </script>
</body>
</html>
